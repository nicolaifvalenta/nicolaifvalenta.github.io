## Colophon

This site is a handful of plain files. It is built with [Eleventy](https://www.11ty.dev/), set in EB Garamond, and hosted on GitHub Pages. The stylesheet is written by hand, and the only script is the one that draws the little previews when you hover over a note or a link.

There are no trackers, no cookies, and no comment section. If something here made you want to disagree, write to me.

Sidenotes appear in the margin on wide screens and as a preview on narrow ones.[^1]

[^1]: Without scripts, they fall back to ordinary notes at the end of the page.
